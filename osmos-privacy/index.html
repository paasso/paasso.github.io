Политика конфиденциальности — «Осмос» (Osmos)

  • Приложение: Осмос (Osmos), Android ru.vikhrov.osmos, iOS ru.vikhrov.osmos
  • Разработчик: Павел Вихров
  • Контакт: chinpokomon373@gmail.com
  • Дата вступления в силу: 2 ноября 2026 г.

1. Кратко

«Осмос» — офлайн-игра. В ней нет регистрации и учётных записей. Разработчик не собирает, не хранит и не передаёт ваши персональные данные. Единственный сторонний компонент, который может обрабатывать данные устройства, — рекламный SDK Яндекса (см. п. 3).

2. Данные, которые хранятся на устройстве

Прогресс (открытые и пройденные уровни) и настройка звука хранятся только локально, в памяти приложения на вашем устройстве. Эти данные никуда не отправляются; они удаляются при удалении приложения или кнопкой «Сбросить прогресс».

3. Реклама (Yandex Mobile Ads SDK)

Игра показывает межстраничную рекламу и рекламу за вознаграждение («продолжить», «открыть уровень») через Рекламную сеть Яндекса (ООО «ЯНДЕКС»). Для подбора, показа рекламы, подсчёта показов и борьбы с мошенничеством SDK может автоматически собирать:

  • рекламный идентификатор устройства (Google Advertising ID / IDFA — на iOS только с вашего разрешения ATT);
  • IP-адрес и приблизительное местоположение по нему;
  • сведения об устройстве и ОС (модель, версия, язык, оператор, тип сети, разрешение экрана);
  • данные о взаимодействии с рекламой (показы, клики).

Эти данные обрабатывает Яндекс как самостоятельный оператор в соответствии со своими документами:

  • Политика конфиденциальности Яндекса: https://yandex.ru/legal/confidential/
  • Правила участия в Рекламной сети Яндекса: https://yandex.ru/legal/partner/
  • Лицензионное соглашение Yandex Mobile Ads SDK: https://yandex.ru/legal/mobileads_sdk_agreement/

Разработчик не получает от Яндекса персональных данных пользователей — только обезличенную статистику показов. Вы можете сбросить рекламный идентификатор или ограничить персонализированную рекламу в настройках устройства (Android: «Настройки → Google → Реклама»; iOS: «Настройки → Конфиденциальность → Отслеживание»).

4. Дети

Игра не предназначена специально для детей младше 13 лет и не собирает сознательно данные детей. Возрастная маркировка: 6+ (без насилия, без внутриигровых покупок). Если вы считаете, что ребёнок передал данные, свяжитесь с нами — мы поможем.

5. Права пользователя

Поскольку разработчик не хранит ваших персональных данных, удалить все локальные данные игры можно, удалив приложение. По вопросам обработки данных рекламным SDK обращайтесь в Яндекс по ссылкам выше. Вопросы к разработчику — по адресу chinpokomon373@gmail.com.

6. Изменения

При изменении политики новая версия публикуется по этому же адресу с новой датой вступления в силу.
